# 라테일 룬워드 티어 분석기

게임 화면의 룬워드 UI를 캡쳐해 활성 룬·왕룬·점수를 판정하는 Electron 툴입니다.

## 실행

```bash
npm install
npm start
```

## 사용법

1. **캡쳐 창**(반투명 테두리)을 게임의 룬워드 UI에 맞게 크기·위치를 조절합니다.
2. 결과 창 또는 캡쳐 창의 **분석** 버튼을 누릅니다. (`Ctrl+Shift+R`)
3. 결과 창에 총점·티어·매칭된 룬 목록이 표시됩니다.

## 점수 기준

- 8슬롯 만점 **500점** = 일반 룬 합 + 왕룬 배율
- 왕룬 옵션 수치는 **2배**, 점수도 **2배** (`점수 × 2`)
- 점수 데이터: `src/rune-data.json` (`npm run sync:scores`)

| 총점 | 판정 |
|------|------|
| &lt; 300 | D 티어 |
| 300 ~ 349 | C 티어 |
| 350 ~ 399 | B 티어 |
| 400 ~ 449 | A 티어 |
| ≥ 450 | S 티어 |

## 왕룬 판별

- UI 위치: 원형 패널 **정중앙** (파란 불꽃 오라) + 바깥 일반 7개
- 활성 룬 아이콘 인식 후, 분홍 효과 줄·패널 효과 OCR·중앙 글리프로 왕룬 판별

## 테스트
