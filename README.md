# 라테일 룬워드 티어 분석기

게임 화면의 **습득한 룬 효과**를 OCR로 읽어 [latale.info/35](https://latale.info/35) 점수 기준으로 티어를 판정하는 Electron 툴입니다.

## 실행

```bash
cd c:\dev\latale-runeword-analyzer
npm install
npm start
```

## 사용법

1. **캡쳐 창**(반투명 테두리)을 게임의 룬워드 UI에 맞게 크기·위치를 조절합니다.
2. 결과 창 또는 캡쳐 창의 **분석** 버튼을 누릅니다. (`Ctrl+Shift+R`)
3. 결과 창에 총점·티어·매칭된 룬 목록이 표시됩니다.

## 티어 기준 (latale.info)

| 점수 | 판정 |
|------|------|
| ≤ 240 | 변경 권장 |
| 241 ~ 380 | 임시용 |
| 381 ~ 470 | 최종용 |
| ≥ 471 | 강력 추천 |

- 왕룬 옵션 수치는 **2배**, 점수것도 **2배** (단, 《통찰》 왕룬은 120점 고정)
- OCR로 핑크(왕룬) 줄을 감지하거나, 수치가 2배인 효과를 왕룬으로 판정합니다.

## 분석기 단위 테스트
